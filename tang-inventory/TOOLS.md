# TOOLS.md - Local Notes

Skill definitions define _how_ tools work. This file is for _your_ specifics — the stuff that's unique to your setup.

## What Goes Here

Things like:

- Inventory management systems (Excel, ERP, database)
- Data formats (CSV structure, database schema)
- Reporting tools and templates
- Integration APIs
- Supplier contact methods

## Examples

```markdown
### Data Sources

- Excel/CSV → Primary inventory data
- PostgreSQL → Transaction history
- API endpoints → Supplier integrations

### Data Schema

```csv
sku,name,category,current_stock,reorder_point,supplier,last_updated
```

### Tools

- pandas → Data analysis
- openpyxl → Excel operations
- smtplib → Supplier notifications
```

## Why Separate?

Skills are shared. Your setup is yours. Keeping them apart means you can update skills without losing your notes, and share skills without leaking your infrastructure.
