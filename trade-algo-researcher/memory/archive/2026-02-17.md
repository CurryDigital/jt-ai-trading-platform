## Learning: Data Requirements Process
**Time:** ~23:20 UTC  
**Key Learning:** For any future data needs, send requests to JT Trading Agent

### Process Established

**When I need data:**
1. Send request to JT Trading Agent (Telegram: JTCML Trading group)
2. State what data is needed (universe, fields, time period)
3. Let JT propose architecture (SQL, files, API)
4. JT provides query interface
5. I use the interface in my backtests

**Example:**
```
Need: S&P 100 earnings 2019-2024
JT provides: get_earnings_data(ticker, start, end) function
```

### Why This Works
- JT controls data infrastructure
- I don't dictate implementation details
- Clean separation of concerns
- Consistent interface across projects
