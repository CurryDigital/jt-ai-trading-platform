# RCA: Backend Crashing / No Data on Website

**Date:** 2026-02-17
**Issue:** Website showing no data, backend intermittently unavailable

---

## Root Cause

**Primary Issue:** Backend process (uvicorn) was terminating/crashing repeatedly

**Evidence:**
1. API returning 502 Bad Gateway errors
2. `pgrep uvicorn` showed no process running at times
3. Local port 8000 not responding
4. After manual restart, data flows correctly

---

## Why It Crashes

### Suspected Causes (in order of likelihood):

1. **Signal SIGTERM/SIGKILL from system**
   - Commands showing "Command aborted by signal SIGTERM"
   - System may be killing processes during exec sessions
   - AWS environment process management

2. **Background process instability**
   - Using `nohup ./start.sh &` is fragile
   - No process supervision (systemd)
   - Process dies when SSH session ends or system restarts

3. **No auto-restart mechanism**
   - When process dies, it stays dead until manual restart
   - No monitoring to detect failures

---

## Resolution Applied

**Immediate Fix:**
- Manually restarted backend: `nohup ./start.sh &`
- Verified data flow: API responding 200 OK
- Website now showing data

**Status:** ✅ RESOLVED (but temporary)

## Permanent Solutions Needed

### Option 1: Systemd Service (RECOMMENDED)
Create a systemd service for automatic startup and restart:

```bash
# /etc/systemd/system/trading-backend.service
[Unit]
Description=JT Trading Platform Backend
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/.openclaw/workspace/jt-ai-trading-platform/backend
ExecStart=/home/ubuntu/.openclaw/workspace/jt-ai-trading-platform/backend/start.sh
Restart=always
RestartSec=10
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

Commands:
```bash
sudo systemctl daemon-reload
sudo systemctl enable trading-backend
sudo systemctl start trading-backend
sudo systemctl status trading-backend
```

### Option 2: Process Manager (PM2)
Use PM2 for Node.js-style process management:

```bash
npm install -g pm2
pm2 start backend/start.sh --name trading-backend
pm2 save
pm2 startup
```

### Option 3: Docker + Auto-restart
Run in Docker with auto-restart policy

### Option 4: Cron Health Check
Add a cron job to check and restart if needed:

```bash
# /etc/cron.d/trading-healthcheck
*/5 * * * * ubuntu /home/ubuntu/.openclaw/workspace/jt-ai-trading-platform/backend/healthcheck.sh
```
