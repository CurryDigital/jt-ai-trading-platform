#### 1. Telegram Alert Service
**File:** `backend/app/services/telegram_alerts.py`

**Capabilities:**
- Trade execution alerts (BUY/SELL with P&L)
- Trade signal alerts
- Drawdown alerts (>5%, >10%, >15%)
- Portfolio drawdown alerts
- Backend restart notifications
- Strategy mode change alerts
- IBKR disconnect alerts
- Daily portfolio summary
- Custom message alerts

**Configuration:**
- Bot token and chat ID via API
- Environment variable support
- Connection testing
- HTML formatting in messages

#### 2. API Endpoints
```
GET  /api/alerts/status          - Check configuration status
POST /api/alerts/configure       - Set bot token and chat ID
POST /api/alerts/test            - Send test alert
POST /api/alerts/daily-summary   - Trigger daily summary
```

#### 3. Integration Points

**Strategy Manager:**
- Sends trade alert after every executed trade
- Includes strategy name, ticker, side, quantity, price, P&L

**Portfolio Risk:**
- Sends drawdown alert when strategy down >5%, >10%, >15%
- Checks on every risk assessment

**Main App Startup:**
- Sends notification when backend restarts
- Helps track crashes and restarts
